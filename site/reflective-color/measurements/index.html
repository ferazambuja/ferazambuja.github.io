Reading the color coordinates and differences

XYZ describes measured or predicted color under the named light and observer conventions. Lab expresses color as lightness (L*), green–red (a*) and blue–yellow (b*) coordinates. D50 names the standard daylight reference used for the i1Pro color calculations here; each experiment's measurement details state its convention.

DeltaE00 is an unsigned color distance. Check which two colors are compared: two measured patterns, forecast versus measurement, or requested versus measured color. RMS (root mean square) instead summarizes the magnitude of a wavelength-by-wavelength spectral difference, in the displayed units. Neither automatically defines visibility.

A signed difference keeps the direction in the order named beside it. For Lab, positive L* means lighter, positive a* redder and positive b* yellower. Repeated-reading movement describes how readings changed, not an uncertainty bound. i1Pro reflectance factor and CR-250 radiance remain separate quantities.

Four-reading sequence

Why use ABBA and BAAB? In this atlas, A is the horizontal pattern and B is the vertical pattern. ABBA is H–V–V–H; BAAB reverses the order to V–H–H–V. Each exact pattern is measured twice. Reversing which pattern comes first and last shows whether the measured H-minus-V direction persists when the reading order changes, while the duplicate readings show how much each unchanged pattern moved within the sequence. This does not remove display history or identify a cause.
