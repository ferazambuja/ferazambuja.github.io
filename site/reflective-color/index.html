Rendering color with six e-paper states

How can a display reproduce photographs when each pixel has only six color choices? I measured how pixel patterns change color, tested an experimental ICC workflow and built a renderer guided by the display's measured native colors.

An image renderer guided by measured colors

The Pimoroni Inky Impression 7.3-inch Spectra 6 module offers black, white, red, yellow, green and blue pixel states. My renderer uses measured references for those states and distributes color error between neighboring pixels to approximate the source image.

Software previews, not panel photographs. Both routes receive the same interpreted, fitted source and use one visualization palette based on measured native-state colors scaled to panel white. These show pixel choices rather than predicting reflected color.

Across eight development images, the renderer reduced mean calculated reference error on every image compared with the matched Pimoroni route, although some local regions worsened. Physical color comparison is pending.

Same color counts, different measured colors

Could the amounts of each native color describe a pattern's output? I compared exact pixel maps with the same color counts and different arrangements. Some rearrangements measured far apart; others stayed close.

In this one-pixel black/yellow comparison, the mean measured colors differed by 18.24 ΔE00. Color counts alone could not describe both results. The comparison does not isolate a physical cause.

The enlarged patterns show digital instructions, not measured appearance. Four i1Pro 3 readings, two per pattern; D50, CIE 1931 2° observer and nominal perfect-diffuser D50 Lab. ΔE00 expresses the distance between the two measured mean colors.

Color management reduced error on a measured grid

I used an experimental ICC profile to convert image colors before the same Pimoroni renderer. On a separate 133-color grid, mean measured error fell from 19.99 to 11.20 ΔE00, using panel white as the Lab reference.

Prediction improved in some tests but did not transfer reliably

Forecasts saved before measurement succeeded for selected exact patterns. For six regions in three new images, a learned model was closer than the additive baseline on all 12 readings, but neither met the chosen engineering limit of 1 ΔE00. Reliable prediction across new colors, returns and image regions remains unresolved.
